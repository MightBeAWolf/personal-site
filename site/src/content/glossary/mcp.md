---
title: MCP
summary: Model Context Protocol — an open standard for connecting an AI agent to external tools, data, and systems.
link: https://modelcontextprotocol.io/
---

MCP defines a common protocol between an AI agent and the tools/data
sources it can call — a database, an API, a filesystem — so integrations
get built once against the protocol instead of once per agent framework.

It shows up in the résumé's AI infrastructure work directly: MCP tool
integration alongside <button type="button" class="glossary-term" data-glossary-term="rag">RAG</button>
pipelines and autonomous agents, and it's how tools like
<button type="button" class="glossary-term" data-glossary-term="claude-code">Claude Code</button>
reach beyond their own sandbox.
