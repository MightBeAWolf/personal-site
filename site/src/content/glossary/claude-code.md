Claude Code works directly in a project's own files and shell rather than a
sandboxed chat window — reading code, making edits, running builds and
tests, and using tools like <button type="button" class="glossary-term" data-glossary-term="mcp">MCP</button>
to reach further systems, all under the operator's direction.

It's the day-to-day AI pair listed under Tools on this page, and this very
glossary system — the content collection, the popup engine, and the
Playwright coverage for it — was built with it.
