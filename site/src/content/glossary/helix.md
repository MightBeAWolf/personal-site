---
title: Helix
summary: A modal, terminal-based text editor with LSP and tree-sitter built in, no plugin system required.
link: https://helix-editor.com/
---

Helix is a modal editor in the vein of Vim and Kakoune, distributed as a
single binary with language servers, syntax highlighting, and tree-sitter
based selection already wired in — no plugin ecosystem to assemble before
it's useful.

It's the daily driver behind this site — its Helix config wires `astro-ls`
in for Astro, and the theme picker a few clicks away on this page is
generated from every theme Helix ships with.
